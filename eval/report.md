## Defeat set

Real cryptography we do not find, measured rather than omitted.

| Sample | Present | Found | Why |
|---|---|---|---|
| `defeat_folded_sigma` | ChaCha20 | ChaCha20 (x64-O0, x86-O0) | No evasion at all: just -O2. The sixteen-byte ChaCha sigma becomes four immediate operands and leaves the file entirely. Short constants are fragile in a way a 256-byte S-box is not, and this measures how fragile. |
| `defeat_masked_sbox` | AES | nothing | The S-box is stored XOR-masked with one byte and unmasked at startup. The cheapest possible evasion, and it defeats every byte pattern we ship. |
| `defeat_p256_limbs` | ECC | nothing | P-256 stored as little-endian 64-bit limbs instead of an octet string. Fixable - expand curve patterns into limb layouts the way word tables already are - and recorded until it is. |
| `defeat_runtime_sbox` | AES | nothing | The S-box is computed at startup from the GF(2^8) inverse, so the table is never in the file. Static byte analysis has nothing to match. Needs a disassembly-based detector, which is a much larger tool. |

## What this does not measure

- **The corpus is built, not collected.** Ground truth is exact and the distribution is ours. These numbers are optimistic for the wild, and no amount of sample count fixes that - only real binaries would.
- **No real static OpenSSL, mbedTLS, or libsodium.** The static arm is reference implementations compiled in, which exercise the same tables but not the same code layout, inlining, or vectorised variants a real library ships. The import signatures for those libraries are therefore shipped untested against a real build.
- **No packed samples.** UPX and friends need a packer in the build, which the corpus does not have. Packing is detected as a status (`degraded-packed`), and that path is unit-tested, but its effect on detection rate is not measured here.
- **No PQC.** Nothing in the corpus contains ML-KEM or ML-DSA, and no signatures ship for them.
- **104 binaries.** Small. Every table above reports exact counts for that reason: 19/20 and 950/1000 are not the same claim and a percentage hides which one you are reading.


## Confidence calibration

Confidence is defined as the measured precision of a signature class on this corpus, and shipped as the lower bound of its 95% Wilson interval, bucketed to 0.05 (test-plan §5).
